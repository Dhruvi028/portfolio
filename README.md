# Dhruvi Shah - Full Stack Developer Portfolio

This is a modern, high-performance portfolio built with Next.js, React, and Tailwind CSS. It features a strict "High-Tech Brutalist" design language tailored for enterprise software engineering.

## Tech Stack
- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Theming:** next-themes (Dark/Light mode support)

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Design Philosophy (High-Tech Brutalism)
- **Monospace Dominance:** Typography is heavily weighted towards `JetBrains Mono` for metadata to simulate a pure engineering environment.
- **Strict Borders:** Removed all rounded corners and soft drop-shadows. The layout relies on exact CSS grid alignments and high-contrast lines.
- **Performance First:** No heavy JS animation libraries. The UI relies strictly on CSS hover states for a zero-latency feel.
